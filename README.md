# 🧼 COSMO CRM (Enterprise Edition)

> Полнофункциональная экосистема автоматизации и управления технологическими, логистическими и финансовыми процессами сервиса стирки ковров и текстиля.

---

## 🚀 Быстрый старт

### Требования
* Node.js v18+ (рекомендуется v20+)

### Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск сервера
node server.js
```

При первом запуске сервер автоматически создаст базу данных SQLite (`barokot.db`) и наполнит её начальными справочниками и демонстрационными данными.

### Доступ к системе
* **Компьютер / Браузер:** [http://localhost:3000](http://localhost:3000)
* **В сети Wi-Fi (смартфоны / планшеты):** `http://<IP_компьютера>:3000`
* **Клиентский трекинг заказа:** `http://localhost:3000/#track-CSM-1048`

---

## 🔑 Ролевой доступ (4-значный PIN)

| Роль | PIN | Описание |
|---|---|---|
| 👑 **Руководитель / Admin** | `0000` | Полная сводка, канбан, финансы, сотрудники, аналитика, настройки |
| 🎧 **Диспетчер** | `1111` | Прием заявок, распределение по районам Самарканда, рассылка SMS/Telegram |
| 🚚 **Курьер (Мобильный)** | `2222` | Мобильный интерфейс забора и доставки, Яндекс.Навигатор, фиксация оплат |
| 🧼 **Мастер цеха** | `3333` | Сенсорный цеховой терминал, ввод замеров ($м \times м$), контроль стирки |

---

## 🛠️ Стек технологий

* **Backend:** Node.js, Express, встроенный транзакционный движок `node:sqlite` (ACID & WAL)
* **Frontend:** Vanilla HTML5, CSS3, JavaScript ES6+, Tailwind CSS, Leaflet Maps
* **Интеграции:** Telegram Bot API, Eskiz.uz SMS Gateway, Яндекс.Карты / Google Maps
