# 📱 Инструкция: Подключение Android Шлюза Телефонии к Cosmo CRM

Шлюз перехватывает входящие звонки на вашем Android телефоне и мгновенно:
1. Ищет клиента в базе по номеру (последние 9 цифр).
2. Показывает всплывающее окно в CRM со звуковым сигналом (Web Audio Chime).
3. Отображает историю клиента, статус, адрес и активный заказ (если есть).
4. Кнопка **«Принять & Оформить заказ»** в 1 клик открывает форму нового заказа с уже заполненным телефоном, именем и адресом!
5. Отправляет уведомление в Telegram с карточкой звонящего.

---

## ⚡ Настройка за 1 минуту через MacroDroid (Бесплатно)

1. Установите **MacroDroid** из Google Play Store (или используйте Termux / Tasker / Automate).
2. Откройте MacroDroid -> нажмите **«Добавить макрос»**.
3. **Триггер (Красный плюс):**
   - Выберите: **«Вызовы / SMS»** -> **«Входящий вызов»**.
   - Выберите: **«Любой номер»**.
4. **Действие (Синий плюс):**
   - Выберите: **«Связь»** -> **«HTTP-запрос»** (или Веб-запрос).
   - Метод запроса: **POST**
   - URL: `http://192.168.2.106:3001/api/telephony/incoming` *(замените IP на локальный IP компьютера в Wi-Fi или внешний домен CRM)*
   - Content-Type: `application/json`
   - Тело запроса (Body):
     ```json
     {"phone": "{call_number}", "source": "android"}
     ```
   - Нажмите галочку **Сохранить**.
5. Назовите макрос **«Cosmo CRM Call Gateway»** и включите его!

## 🧪 Тестирование без звонков

В шапке CRM есть кнопка **«Тест звонка»**. При клике:
- Прозвучит звуковой сигнал входящего звонка.
- Откроется карточка входящего вызова с номером `+998 90 777-88-99`.
- Нажатие **«Принять & Оформить заказ»** мгновенно перенесёт номер в модальное окно оформления заказа.

Также можно отправить тестовый вызов через curl/PowerShell:
```bash
curl -X POST http://localhost:3001/api/telephony/incoming -H "Content-Type: application/json" -d "{\"phone\": \"+998901234567\"}"
```
